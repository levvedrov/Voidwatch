# Images to Create

Place finished images in the paths listed below.

---

## eranoid.com  →  website/eranoid/public/

| File | Size | Description |
|------|------|-------------|
| `favicon.ico` | 32×32 | Eranoid icon. Simple geometric mark — e.g. stylised "E" or abstract node/circuit shape. Dark bg, white/blue mark. |
| `images/og.png` | 1200×630 | Open Graph card. Dark background, "ERANOID" wordmark center-left, tagline below, subtle grid/glow. Used when sharing eranoid.com on social. |
| `images/team/lev.jpg` | 400×400 | Founder photo. Square crop, head+shoulders. Used in the Team section team card. |

## voidwatch.eranoid.com  →  website/voidwatch/public/

| File | Size | Description |
|------|------|-------------|
| `favicon.ico` | 32×32 | Voidwatch icon. Can share the same as Eranoid or be a distinct mark (e.g. eye/radar shape). |
| `images/og.png` | 1200×630 | Open Graph card for Voidwatch. Dark bg, "VOIDWATCH" + "Beta" badge, tagline "AI-assisted endpoint behavior monitoring", subtle glow. |
| `images/dashboard.png` | 1280×800 | Screenshot of the Voidwatch dashboard. Take a screenshot of the running Electron dashboard with real data visible (Dashboard tab). Crop to the content area. This appears in the hero section of voidwatch.eranoid.com. |

---

## Notes
- All backgrounds should match the site bg: `#07070a` (near-black)
- Accent colors: blue `#4a90e2`, violet `#8b5cf6`, cyan `#06b6d4`
- No shields, no skulls, no Matrix effects
- OG images: clean, minimal, text-focused — they appear as social preview cards
